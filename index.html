Accessibility-First Projects

Navic Echo

An accessibility-first typing practice web app built for screen reader users. It announces each word along with clear letter-by-letter spelling so blind and visually impaired learners can build typing speed and accuracy with zero visual barriers.

Open Project

Seventh Vision-X

An accessibility-first, privacy-focused browser document reader designed for blind and visually impaired readers. It cleans out distracting symbols and emojis before reading PDF and text files sentence by sentence alongside TalkBack and NVDA.

Open Project

eXponentialBridge Focus

An accessibility-first local AI assistant engineered with predictable keyboard navigation, live screen reader announcements, and clean spoken responses. It lets users ask questions and read local PDFs offline without clutter or focus traps.

Open Project

Neural Voice Artists

An accessibility-first text-to-speech studio built for blind and visually impaired students and researchers. It converts large study notes into natural neural speech and downloadable MP3 files with full keyboard control and zero paywalls.

Open Project

A11y Metric Pro

An accessibility-first, keyboard-driven audio and video editing suite made for blind and low-vision creators. It provides spoken live status updates and simple hotkeys for precise trimming and volume balancing without needing a mouse.

Open Project

AI Web Application Sci-Fi UI

An accessibility-first offline AI assistant pairing a high-contrast dark interface with full keyboard shortcuts and clean spoken feedback. Users can read documents, monitor system health, and interact privately on their own device.
